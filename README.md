# ⚔️ Term Wars — Algebra Combat for Form 1

A practice game for Form 1 Algebra 1 at Caribbean Union College Secondary School (CUCSS), Trinidad.
Made by Mr. Legall for classes 1A, 1B and 1C.

The whole game is one file, `term-wars.html`. It runs in any phone or computer browser. There is no login, no app to install, and no server: each student's progress is saved on their own device.

---

## What students practise

The game has seven worlds. Each world has two stages.

| World | Stage 1 | Stage 2 | How it opens |
|---|---|---|---|
| 1 · Meet the Terms | Term Sorter: drag terms into buckets | Term Spotter: coefficient, variable, constant, how many terms | Always open |
| 2 · Collect | Like or Unlike? | Simplify Race: collect like terms, or press CANNOT SIMPLIFY | Pass World 1 |
| 3 · Word Builder | Words to Algebra (sentences and Trinidad stories) | Algebra to Words | Pass World 1 |
| 4 · Substitute | Replace: put the number in, keep the hidden × | Calculate: replace first, then calculate | Pass World 1 |
| 5 · Brackets | Expand | Expand and Collect | Pass World 1 + a code word from the teacher |
| 6 · Powers | What Powers Mean | Simplify with Powers | Pass World 1 + a code word from the teacher |
| 7 · Multiply & Divide | Multiply Terms | Divide Terms | Pass World 1 + a code word from the teacher |

Worlds 5–7 follow the order of STP Caribbean Mathematics Book 1, Chapter 12. The teacher says the code word in class on the day that topic is taught, so each class opens the world when it is ready. (The code words are in the teacher panel and in the settings at the top of the file. They are not written here because this page is public.)

**Scope rules built into every question**
- **No negative numbers.** A minus sign only ever means "take away" when you have enough (9m − 4m, or 3(x − 2) = 3x − 6). No answer is ever negative, and no answer starts with a minus.
- Whole-number coefficients only. Division is shown as ÷ or as a fraction with a vinculum (a horizontal line).
- Powers appear only from World 6. Before that, the rule is "the variable decides the bucket". World 6 grows it into "same letter AND same power".
- The letters q and g are never used as variables, because next to a number they look like a 9 (9q, 9g).
- **No giveaway options.** In questions like "Are these like or unlike?", two options start with each verdict, so the first word never gives the answer away. One of them is the right verdict with the wrong reason, so students must read the reason.

Questions are made fresh every time, so playing again is real practice, not memorising.

## The one scoring rule

Every stage works the same way.

- **10 questions per run:** 8 practice questions, then 2 boss rounds.
- **One try per question.** Only answers that are right the **first time** count. A wrong answer gets an explanation, and the game moves on.
- **8 out of 10 passes the stage.** Stage 2 opens when Stage 1 is passed.
- **Replay as often as you like.** Each replay has new questions. The game keeps the best score, and a pass is never lost.
- **No timer and no penalties** in scored runs. After passing, an optional 60-second **Speed Round** is there for fun. It never counts.
- Before a stage is played for the first time, a **How it works** page shows worked examples. It can be opened again from the stage card.

### Speed rounds and streaks
A speed round scores **points**. Answers right in a row build a **streak**: 3 in a row doubles each answer's points (x2), 6 in a row gives x3, and 9 or more gives x4. One wrong answer resets the streak to zero. The game keeps each student's best points for each stage. Speed rounds never change a stage score, a ticket or a mark.

### Boss rounds (find the fault)
The last two questions of every stage show a fictional student's work (Maya, Jakari, Tiara, Marcus and others). The student taps the **first wrong line**, then **names the fault**. A boss round counts only if both steps are right first time. The wrong line is always a wrong plan or claim, never a true calculation marked wrong.

### The Wars — mistakes with names
When a student makes a common mistake, the game calls it by name, so the class can say "that's a War 2" in a lesson.

| War | Name | Example of the mistake |
|---|---|---|
| War 1 | Growing the power | 3x + 5x = 8x², or x² + x² = 2x⁴ |
| War 2 | Joining unlike terms | 7x + 2 = 9x, or 3x² + 3x = 6x² |
| War 3 | Dropping the variable | 4x + 3x = 7, or 12x ÷ 4 = 3 |
| War 4 | The half-multiplied bracket | 3(x + 4) = 3x + 4 |
| War 5 | Stuck-together substitution | x = 3, so 2x = 23 |

## Marking: the completion mark

### The idea behind it
Term Wars is **homework practice**, so it gets a **completion mark for doing the practice, not a mark for how high the scores are.**

The game already makes "doing it" mean something real: a stage cannot be passed without 8 out of 10 right the first time. Marking the size of the scores (a 10 worth more than an 8) would treat practice like a test. It would push students to rush, to replay only for the number, or to hand the phone to someone else. **Understanding is assessed separately, in Quiz 2**, which the student does on their own.

A student who keeps going until every stage is passed gets full marks. That persistence is the habit the mark rewards.

### The method
For the worlds set in the assignment:

- **1 mark** for each stage passed (best score of 8 or more)
- **½ mark** for each stage played but not passed, so a student who tried hard but is still stuck gets some credit
- **0** for a stage not played

**Mark = (total of those) ÷ (number of stages set) × 10**, rounded to a whole number.

**Examples** (assignment: Worlds 1–4, which is 8 stages, marked out of 10)

| Student's stages | Working | Mark |
|---|---|---|
| Passed all 8 | 8 ÷ 8 × 10 = 10 | **10** |
| Passed 5, tried 2 more without passing, 1 not played | (5 + ½ + ½) ÷ 8 × 10 = 7.5 | **8** |
| Played Stage 1 and Stage 2 of World 1, passed neither | (½ + ½) ÷ 8 × 10 = 1.25 | **1** |
| Sent no valid ticket | — | **0** |

**What never affects the mark**
- The Wars counts. They are for teaching. If mistakes cost marks, students learn to fear the game instead of learning from it.
- Speed rounds.
- Scores in worlds that were not set for the assignment.

**Late tickets.** If the teacher sets a due time, a ticket sent after it is late. The teacher chooses whether late tickets get full, half or no marks (half is the default). If a student has both an on-time ticket and a late one, the student gets whichever gives the higher mark.

The teacher sets all of this in the **This assignment** box in the teacher panel: which worlds count, the mark out of (10 by default), the half mark (on by default), the due time and the late rule. These settings are remembered on the teacher's device.

## Tickets: how results reach the teacher

1. When a student has played, they press **🎟 My ticket** on the worlds screen.
2. The ticket shows each stage's best score, the Wars from their latest runs, and a **6-character code** (for example `ABC-234`).
3. They press **📨 Submit my ticket**. The class Google Form opens with everything filled in. They press Submit.

**The code is a seal.** It is made from the student's **name, class and scores**. If a score is changed, or a student uses someone else's code, the teacher's checker marks the ticket **Not valid**.

**Backups if the Form does not open:** copy the message and send it on WhatsApp or by email, take a screenshot, or write the code in the exercise book.

### The Ticket Drop Form — one Form for every tool
All of Mr. Legall's games and study tools send tickets to **one** Google Form, *Mr. Legall's Ticket Drop*, with five short-answer questions in this order:

**Name · Class · Game · Result · Code**

The **Game** column keeps the tools apart. Each tool's checker skips rows from other games.

**Looking after the Form**
- **Never delete or reorder the five questions.** Each has a hidden entry number that the tools rely on. Changing the wording is fine. A deleted and re-made question gets a new number and breaks every tool.
- New questions, if ever needed, go at the bottom.
- **Response editing stays OFF**, and **"Limit to 1 response" stays OFF**: students send a new ticket as they progress, and the checker uses their latest one.
- **Each September**, keep the same Form but start a new response Sheet: Responses → Select response destination → Create a new spreadsheet, for example `FORM_Ticket Drop (Responses 2027–28)`.
- The response Sheet holds names and scores. Keep it private.

## Teacher panel

Open it by typing the **teacher code** in the small box on the title screen.

- **How scoring works** — a short reminder of the rules above.
- **Code words** for Worlds 5–7.
- **This device (for testing)** — open every world and stage on your own device, or reset it.
- **The Google Form** — one click sends a test ticket, already filled in, so you can check that the Form works.
- **Check one ticket** — type a name, class, result and code.
- **Check many tickets at once**
  1. Open the Form's response Sheet, select the rows from Timestamp across to Code, and copy.
  2. Set **This assignment** (worlds, mark out of, half mark, due time, late rule).
  3. Paste the rows and press **Check all**.
  4. You get one table per class: **one row per student**, sorted by surname, with every ticket they sent bundled together. The row shows the world scores, worlds passed, stages done, **the mark**, number of tickets, Wars to watch, and a note (for example "late (half marks)" or "1 ticket did not check out").
  5. **🖨 Print class lists** prints plain black-and-white pages, one class per page. **📋 Copy for Sheets** pastes the same rows, with the mark, into a spreadsheet or markbook.

Students who sent no ticket do not appear, so compare the list with your class register.

## Settings at the top of the file

Open `term-wars.html` in a text editor. The first lines of the script are the settings:

| Setting | What it does |
|---|---|
| `TEACHER_NAME`, `TEACHER_EMAIL` | Shown on tickets and in the backup message |
| `CLASSES` | The class choices, e.g. `['1A', '1B', '1C']` |
| `TEACHER_CODE` | Opens the teacher panel |
| `WORLD_CODES` | The code words for Worlds 5, 6 and 7 |
| `FORM_URL`, `FORM_FIELDS` | The Ticket Drop Form address and its five entry numbers |
| `TICKET_SALT` | Part of the seal. **Do not change it during a school year**, or every ticket already sent will stop checking out |
| `PASS_MARK` | Right-first-time answers needed to pass a stage (8) |
| `SPEED_SECONDS` | Length of a speed round (60) |

After changing a setting, upload the file to GitHub again.

## Honest limits

- **Anyone with the link can play.** That does no harm: nothing is recorded until someone submits the Form.
- **Anyone with the Form link could submit to it.** A name that is not on a class list stands out in the checker.
- **The seal stops edited scores and borrowed codes, but it cannot know who was holding the phone.** If someone else plays under a student's name, the ticket is still valid. That is the same risk as any homework done at home, and it is why understanding is marked in Quiz 2, not here.
- **The file can be read by anyone**, including the teacher code and code words. The worst a curious student can do is open worlds early on their own device. Their real scores are still what gets sealed.
- **Progress lives on one device, for one player.** If a student clears their browser or changes phones, their progress starts again, and two students sharing one device share one save. A ticket already submitted is not affected. (Separate players on one device and a "take my progress home" code are planned; see the development handoff of 18 November 2026.)

## Updating the game on GitHub

1. Make changes to `term-wars.html` (or get a new version).
2. In the GitHub repository, upload the new file in place of the old one, **with the same name as the file already there**. A different name makes a second copy instead of replacing the live game.
3. GitHub Pages updates within a minute or two. Students keep their saved progress.
4. Open the game, type the teacher code, and press **Send a test ticket to the Form** to check that everything still works.
